# Pomodoro 25/5

Temporizador Pomodoro simple para estudiar desde el navegador.

## Funciones

- 25 minutos de enfoque y 5 minutos de descanso por defecto.
- Iniciar, pausar, reiniciar y saltar etapa.
- Pitido y vibración al terminar.
- Notificaciones del navegador opcionales.
- Inicio automático de la siguiente etapa.
- Contador de Pomodoros y minutos de enfoque del día.
- Meta diaria configurable.
- Tema oscuro/claro.
- Atajos: `Espacio`, `R`, `S`, `M`.
- Configuración y estadísticas guardadas en `localStorage`.

## GitHub Pages

El sitio se despliega automáticamente desde `main` mediante `.github/workflows/deploy-pages.yml`.

> Nota: para que sonido y notificaciones funcionen correctamente, el navegador puede requerir una primera interacción y permiso de notificaciones. La pestaña debe permanecer abierta; una web estática no puede generar avisos después de cerrarla por completo.

## Archivos anteriores

La carpeta `Aguita/` conserva el proyecto Android anterior únicamente como respaldo y no participa en el despliegue web actual.
